# 3D and WebGL

three.js in a Lantern card: theme-aware, sized by its container, rendering only while something moves. Read `interaction.md` first for sizing, drag and state.

## Load

HTML visuals refuse external script URLs, including a CDN. Put the library next to the page and import it by a relative URL, or inline the script. Module scripts run after the page is parsed, so put the stage markup above them; the card then has its final height before the library arrives.

```html
<script type="module">
import * as THREE from './three.module.js'
import { OrbitControls } from './OrbitControls.js'
// …
</script>
```

## Setup: sized by the stage, background from CSS

```html
<style>
  :root { --stage-a: #ffffff; --stage-b: #e9edf3; }
  :root[data-theme="dark"] { --stage-a: #262931; --stage-b: #111215; }
  .stage { position: relative; height: 420px; border-radius: 14px; overflow: hidden;
    border: 1px solid var(--lt-border-strong); background: radial-gradient(120% 100% at 30% 20%, var(--stage-a), var(--stage-b)); }
  .stage canvas { display: block; width: 100%; height: 100%; touch-action: none; }
  :root:fullscreen .stage { height: calc(100vh - 120px); }
</style>
<div class="stage" id="stage"><button data-lt-fullscreen style="position:absolute;right:10px;top:10px">⛶</button></div>
```

```js
const stage = document.getElementById('stage')
const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true })   // alpha: the CSS gradient shows through
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
renderer.toneMapping = THREE.NeutralToneMapping                                // keeps hues; ACES washes pastels out
stage.prepend(renderer.domElement)
const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(35, 1, 0.1, 200)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
function resize() {
  const w = stage.clientWidth, h = stage.clientHeight
  if (!w || !h) return
  renderer.setSize(w, h, false)            // false: CSS keeps the canvas at 100% × 100%
  camera.aspect = w / h
  camera.updateProjectionMatrix()
  requestRender()
}
new ResizeObserver(resize).observe(stage)
```

Never `renderer.setSize(innerWidth, innerHeight)` in an inline card: that is the card's own height, so the page would chase it.

## Render on demand

```js
let raf = 0, last = performance.now()
function requestRender() { if (!raf && lantern.visible) raf = requestAnimationFrame(frame) }
function frame(now) {
  raf = 0
  const dt = Math.min(0.05, (now - last) / 1000); last = now
  const moved = controls.update(dt)        // true while damping still moves the camera
  renderer.render(scene, camera)
  placeLabels()
  if (moved || controls.autoRotate) requestRender()
}
controls.addEventListener('change', requestRender)
lantern.on('visibility', (v) => { if (v) { last = performance.now(); requestRender() } })
```

Call `requestRender()` after anything changes: hover, slider input, a theme change. Auto-rotate stays off under `prefers-reduced-motion`.

## Theme-aware materials

```js
const PALETTE = { light: { carbon: '#40444d', oxygen: '#e2483d' }, dark: { carbon: '#8f96a3', oxygen: '#ff7468' } }
const mats = { carbon: new THREE.MeshStandardMaterial({ roughness: 0.32 }), oxygen: new THREE.MeshStandardMaterial({ roughness: 0.32 }) }
function applyTheme() {
  const p = PALETTE[document.documentElement.dataset.theme === 'dark' ? 'dark' : 'light']
  for (const k in mats) mats[k].color.set(p[k])
  line.material.color.set(token('--lt-fg'))         // token(): interaction.md "Theme colors in JS"
  requestRender()
}
lantern.on('theme', applyTheme)
```

- Dark objects vanish on a dark stage. Lighten neutrals (grays, carbon, axes) in dark mode and keep hues.
- For soft reflections without any download, use `scene.environment = new THREE.PMREMGenerator(renderer).fromScene(new RoomEnvironment(), 0.04).texture`, from `three/addons/environments/RoomEnvironment.js`. Add one `DirectionalLight` as the key light.
- `THREE.Color` takes hex and `rgb()`, not `color-mix()`: resolve tokens with `token()`.

## Picking, hover and click

```js
const ray = new THREE.Raycaster(), ndc = new THREE.Vector2()
function hit(e) {
  const r = renderer.domElement.getBoundingClientRect()
  ndc.set(((e.clientX - r.left) / r.width) * 2 - 1, -((e.clientY - r.top) / r.height) * 2 + 1)
  ray.setFromCamera(ndc, camera)
  return ray.intersectObjects(pickables, false)[0]
}
let down = null
renderer.domElement.addEventListener('pointerdown', (e) => { down = { x: e.clientX, y: e.clientY } })
renderer.domElement.addEventListener('pointermove', (e) => { if (!e.buttons) showTip(hit(e), e) })
renderer.domElement.addEventListener('click', (e) => {
  if (!down || Math.hypot(e.clientX - down.x, e.clientY - down.y) > 5) return   // that was a rotation, not a click
  select(hit(e))
})
```

For small targets (planets, points), pick the nearest projected object within about 14 px rather than requiring an exact ray hit.

## Labels and tooltips in the DOM

Crisp text, theme colors for free, and no font loading. Project each anchor point after rendering:

```js
function placeLabels() {
  const w = stage.clientWidth, h = stage.clientHeight
  for (const { el, pos } of labels) {
    const v = pos.clone().project(camera)                 // pos in world space
    el.style.display = v.z > 1 ? 'none' : ''              // behind the camera
    el.style.transform = 'translate(-50%, -50%) translate(' + ((v.x + 1) / 2 * w) + 'px,' + ((1 - v.y) / 2 * h) + 'px)'
  }
}
```

Keep labels in an absolutely positioned layer over the canvas with `pointer-events: none`. Hide labels that would overlap one already placed (keep the selected one first), and dim those the surface hides: raycast from the camera to the label point.

## Camera state

With damping, the camera keeps gliding after the pointer is released. Save it when it comes to rest, in the render loop:

```js
let wasMoving = false
// in frame(), after controls.update():
if (wasMoving && !moved) lantern.setState({ ...state, cam: camera.position.toArray().map((v) => +v.toFixed(3)), target: controls.target.toArray() })
wasMoving = moved
// at start:
const s = lantern.getState()
if (s && s.cam) { camera.position.fromArray(s.cam); controls.target.fromArray(s.target || [0, 0, 0]) }
```

Frame the subject from its bounding radius and the field of view: `distance = radius / Math.sin(fov / 2)`. Pull back further on tall, narrow stages.

## Limits

- One renderer per visual. When you rebuild a scene, reuse the geometries and materials, or `dispose()` them.
- A page keeps about 16 live WebGL contexts and drops the oldest. A long chat with many 3D cards loses its older ones. Lantern then shows a "paused" overlay with a resume button, so never create extra contexts (offscreen helper canvases, one renderer per sub-view).
- Some users get software rendering. Keep inline scenes modest (under about 100k triangles, no post-processing), cap the DPR at 2, and make the loop rest when idle.
- `OrbitControls` sets `touch-action: none` on its canvas, so on touch screens a 3D card catches vertical swipes. Keep inline stages under about 450 px tall.

## A shader without three.js

A full-screen triangle and a fragment shader. Adapt the resolution so slow GPUs stay smooth:

```js
const gl = canvas.getContext('webgl2', { antialias: false })
if (!gl) { /* show a short message instead */ }
// compile a vertex shader `gl_Position = vec4(p, 0., 1.)` and your fragment shader, then:
gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer())
gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-1, -1, 3, -1, -1, 3]), gl.STATIC_DRAW)
let quality = Math.min(devicePixelRatio, 1.5)
function resize() { canvas.width = stage.clientWidth * quality; canvas.height = stage.clientHeight * quality; gl.viewport(0, 0, canvas.width, canvas.height) }
// once a second: fps < 30 → quality *= 0.8 (down to 0.45) and resize(); fps > 55 → raise it again
```

Pass theme colors as `vec3` uniforms (resolve with `token()`) and re-send them on `theme`. Feed the pointer as a uniform for interaction.
